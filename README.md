# Pengjie Liu · Academic Homepage

This repository contains the personal academic homepage of **Pengjie Liu (刘鹏杰)**, a researcher working at the intersection of legal artificial intelligence, information retrieval, knowledge graphs and legal reasoning.

The live homepage is available at **[sustech-tp.github.io](https://sustech-tp.github.io/)**. Public academic records can be found through [Google Scholar](https://scholar.google.com/citations?user=PYnqyTMAAAAJ&hl=zh-CN), and research code is collected in the [SUSTech-TP GitHub repositories](https://github.com/SUSTech-TP?tab=repositories).

## Site structure

The homepage presents a concise overview of research interests, recent news, education and employment history, selected projects, academic services, publications and contact information. Publication details and citation records should be checked against the linked scholarly profile for the most current version.

## Local development

```bash
pnpm install
pnpm dev
```

To create a production build:

```bash
pnpm check
pnpm build
```

The site is a static React and Vite application. The generated files are placed in `dist/public` for static hosting.
